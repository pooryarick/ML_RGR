# Интерактивный дашборд для прогнозирования стоимости бриллиантов (ML Inference)

Данный репозиторий содержит исходный код многостраничного веб-приложения (дашборда), разработанного на базе фреймворка **Streamlit**. Приложение предназначено для проведения разведочного анализа данных (EDA) и демонстрации инференса (вывода) предварительно обученных моделей машинного обучения, решающих задачу регрессии — предсказание рыночной стоимости бриллиантов на основе их физических и геометрических характеристик.

Проект выполнен в рамках расчетно-графической работы (РГР) по дисциплине «Машинное обучение и большие данные».

---

## Основной функционал

Приложение имеет модульную структуру и состоит из 4 логических разделов, переключение между которыми осуществляется через боковую панель навигации:

1. **О разработчике:** Информация об авторе проекта и контексте разработки.
2. **Описание набора данных:** Детальное описание предметной области, признаков датасета, особенностей предобработки (фильтрация аномалий, кодирование, масштабирование) и интерактивная таблица для просмотра исходных данных.
3. **Визуализация зависимостей (EDA):** Построение аналитических графиков с использованием `matplotlib` и `seaborn` (распределение цен, матрица корреляций, влияние веса на стоимость, распределение цен по огранке).
4. **Инференс моделей ML (Генерация прогнозов):** Главный вычислительный модуль, поддерживающий два режима:
   * **Единичный прогноз:** Ручной ввод параметров бриллианта через ползунки и числовые поля. Встроена строгая валидация (не допускается ввод нулевых или отрицательных физических размеров).
   * **Пакетный прогноз:** Загрузка пользовательского `.csv` файла с множеством записей, массовый расчет стоимости и экспорт результатов в виде нового `.csv` файла.

## Доступные модели машинного обучения

В приложении реализована возможность динамического выбора одной из 6 оптимальных моделей, предварительно обученных и сериализованных с помощью `pickle`. Загрузка моделей оптимизирована механизмом кэширования (`@st.cache_resource`).

| Название модели | Алгоритм / Особенности | Точность (R²) |
| :--- | :--- | :--- |
| **Классическая модель** | Полиномиальная регрессия + ElasticNet (Optuna) | 0.97 |
| **Бэггинг** | `BaggingRegressor` (GridSearchCV) | 0.99 |
| **Градиентный бустинг** | `GradientBoostingRegressor` из `sklearn` (Optuna) | 0.99 |
| **CatBoost** | Высокоэффективная реализация градиентного бустинга (Optuna)| 0.99 |
| **Стэкинг** | `StackingRegressor` (комбинация базовых моделей) | 0.99 |
| **Нейронная сеть (MLP)** | Многослойный перцептрон, оптимизация lbfgs (Optuna) | 0.94 |

---

## Используемые признаки (Features)

Для получения прогноза модели ожидают следующие характеристики камня:
* `carat` — Вес бриллианта (в каратах).
* `cut`, `color`, `clarity` — Качество огранки, цвет и чистота (категориальные признаки, закодированные в числовые ранги).
* `depth`, `table` — Глубина (в %) и ширина площадки (в %).
* `x`, `y`, `z` — Физические размеры камня (длина, ширина, высота в миллиметрах).

**Целевая переменная (Target):** `price` — рыночная стоимость бриллианта в долларах США.

## Установка и локальный запуск
Склонируйте репозиторий на свой локальный компьютер:


```bash
   git clone https://github.com/pooryarick/ML_RGR
   cd ML_RGR/
```
(Рекомендуется) Создайте и активируйте виртуальное окружение:

```bash
   python -m venv venv
   ### Для Windows:
   venv\Scripts\activate
   ### Для macOS/Linux:
   source venv/bin/activate
```
Установите необходимые зависимости. Базовый стек: streamlit, pandas, numpy, matplotlib, seaborn, scikit-learn, catboost.

```bash
   pip install streamlit pandas numpy matplotlib seaborn scikit-learn catboost
```
Запустите приложение:

Bash
   streamlit run app.py
После выполнения команды дашборд автоматически откроется в вашем браузере по адресу http://localhost:8501.
